# القضاء والعدل — نظام القضايا

## رموز الدخول التجريبية
- القاضي: `3dl-srab`
- المحامي: `3dl-mohami`
- المحقق: `3dl-muhaqqiq`

## الصلاحيات
- **الزائر:** يشاهد رقم القضية واسمها وملخصها فقط.
- **القاضي:** يرى التفاصيل، ينشئ قضية، ويغير الحالة بين مفتوحة / قيد التحقيق / محالة للمحكمة / مغلقة.
- **المحقق:** ينشئ قضية ويضيف محاضر التحقيق.
- **المحامي:** يرى تفاصيل القضايا ويضيف مذكرات قانونية.

> هذه نسخة GitHub Pages ثابتة، لذلك البيانات المحفوظة بواسطة JavaScript تكون محلية على المتصفح. لا تعتبر رموز الدخول حماية أمنية حقيقية؛ للحماية الفعلية بين عدة مستخدمين نحتاج خادماً وقاعدة بيانات وتسجيل دخول حقيقياً.
